# Security policy

`rlscan` is a read-only scanner. It never writes data and only calls endpoints a normal visitor can reach.

## Reporting a vulnerability in rlscan itself
Email **diego@barrsec.com.mx** with details and steps to reproduce. Please don't open a public issue for a vulnerability. You'll get an acknowledgement within a few days.

## Responsible use
Only scan applications you own or are explicitly authorized to test.
